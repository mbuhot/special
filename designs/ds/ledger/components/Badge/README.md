A pill that names the state of a record.

Provide: one word. The state modifier sets the colours: `--lead --draft` neutral; `--qualified --proposal --sent --open` info; `--won --paid --done` success; `--lost --void --overdue` danger.

- Use `ds-badge--inline` when the badge follows text on the same line.
- The word carries the meaning; colour reinforces it.
