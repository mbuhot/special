A label above a form control: input, select, textarea or checkbox.

Provide: a `label.ds-field__label` and one control (`ds-input`, `ds-select`, `ds-textarea`, `ds-checkbox`). Width modifiers `--sm` (150px), `--md` (180px), `--lg` (240px) and `--grow` size the field.

- Use `ds-select--auto` for a select that fits its content and `ds-select--md` for a fixed width.
- A checkbox stands alone in a table cell or beside its own label text.
- Placeholders are `ds-text-muted`; they do not replace the label.
